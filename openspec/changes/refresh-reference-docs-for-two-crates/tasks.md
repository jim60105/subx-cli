**What the gate actually verifies for this change.** The four steps are the series' standard gate, reproduced unchanged, and for this change three of the four are close to vacuous — a fact worth stating rather than disguising, because it is why phase 8 exists.

- **9.1** touches nothing this change edited. Unlike C3, this change modifies no manifest and no `.rs` file: `design.md` Decision 1 keeps the `[package.metadata.docs.rs]` narrowing and the D11 re-export prose in C3. `cargo fmt` and `clippy` therefore verify only that the tree was already green.
- **9.2** is the weakest step and is retained for form. No test in either crate asserts anything about a Markdown file, and no rustdoc path is edited here, so the filter is deliberately minimal.
- **9.3** is the real gate, and its meaning here is different from its meaning in C3. After C3, `scripts/quality_check.sh` contains the three-predicate governance check — but this change touches neither `openspec/` tree, neither `AGENTS.md`, nor `openspec/split-capabilities.txt`, so all three predicates should be unaffected. A red verdict from this step is therefore evidence of an *unintended* edit, which makes it useful as a negative check: it asserts that a documentation change stayed inside `docs/`. The step also runs the `--workspace` doc build, which for this change confirms only that nothing regressed.
- **9.4** has almost no residual power here, in contrast to C3 where it was the load-bearing step. This change edits no doc comment, so no doctest and no intra-doc link is in scope. It is run to confirm the tree is still green.
- **Phase 8 is where this change is actually verified.** The acceptance condition (`grep -rn 'src/' docs/` with no unqualified hit), the three-symbol absence check, the table-of-contents consistency check, and the `AGENTS.md`-versus-architecture-document agreement check are the four assertions that would fail if this change were done wrong, and not one of them is reachable by any step of the standard gate. A green gate here is a necessary condition and a very weak one; phase 8 is the sufficient one.
