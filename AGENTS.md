# AGENTS.md

Instructions for AI coding agents working on **SubX-CLI**.

## Project Overview

**SubX-CLI** is an advanced AI-powered command-line tool for automated
subtitle processing. It intelligently matches, renames, and converts
subtitle files for video collections. Key features:

- AI-based subtitle-to-video matching
- Batch processing with parallel execution
- Format conversion between SRT, ASS, VTT, and SUB
- Timeline correction via Voice Activity Detection (VAD)
- Robust file organization with dry-run previews
- Comprehensive cache management for repeated operations

- **Repository:** <https://github.com/jim60105/subx-cli>
- **Language:** Rust (edition 2024)

## Rust Coding Guidelines

- All code comments and rustdoc must be written in **English**.
- The `#[deprecated]` attribute is **prohibited**. If tempted to use it,
  remove the item and update every call site instead.
- Any unimplemented code must be marked with a `//TODO` comment. Unless the
  requirements document explicitly permits phased implementation, **`TODO`
  is forbidden** — finish your work.
- Never parse `Cargo.lock` (oversized; saturates context). Never hand-edit
  `Cargo.lock` — it is regenerated by Cargo.
- Always run `cargo fmt` and `cargo clippy -- -D warnings` and fix every
  warning before submitting code.
- Always run `timeout 240 scripts/quality_check.sh` to verify quality. If it
  exceeds 240 seconds, rerun with `-v` for details.
- For tests, use `cargo nextest run || true` (the `|| true` is required due
  to a known issue with `nextest` in this project's setup). Do **not** use
  `cargo test`.
- Check coverage with `timeout 240 scripts/check_coverage.sh -T`.
- Follow [Test Guidelines](docs/testing-guidelines.md) strictly:
  - Always use `TestConfigService` for configuration in tests.
  - Never modify global state in tests.
- Follow [Rustdoc Guidelines](docs/rustdoc-guidelines.md) for public API
  documentation.
